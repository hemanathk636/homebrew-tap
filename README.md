# hemanathk636 Homebrew Tap

Official Homebrew tap for [SecretGuard](https://github.com/hemanathk636/secretguard) — Sub-millisecond Terminal Secret & Privacy Guard.

## Installation

```bash
brew tap hemanathk636/tap
brew install secretguard
```

## Enable Shell Hook

### Zsh (macOS / Linux)
```zsh
eval "$(secretguard hook zsh)"
```

### Bash
```bash
eval "$(secretguard hook bash)"
```
